# Interactive Product Sales Dashboard

## Overview

This project is an Interactive Data Visualization Dashboard created for the Frontend Intern Coding Challenge.

The application uses Streamlit as the main web application and ReactJS for interactive dashboard components.

## Features

- Product search
- Category filter
- Region filter
- Total revenue calculation
- Units sold calculation
- Average revenue calculation
- Revenue by Category bar chart
- Monthly Revenue line chart
- Sales data table
- Loading state
- Error handling
- Responsive design
- Animations and transitions
- Tooltips
- Accessibility labels
- Custom React Hook

## Technologies Used

- Python
- Streamlit
- Pandas
- ReactJS
- JavaScript / JSX
- Chart.js
- HTML
- CSS
